## ⚠️ **Moderate Issues**

### 8. **Block-Level Reading Has Failure Points**
**Problem**: The block-level reading workflow (Obsidian-Guide.md, lines 100-140) requires:
1. Read entire file into memory
2. Search for block ID
3. Calculate line number
4. Re-read with view_range

**Issues**:
- If file is huge, step 1 burns tokens anyway
- If block ID not found, falls back to full file (no savings)
- If multiple blocks match, uses first (might be wrong section)

**Recommendation**:
- Add size check: "If file >1000 lines, use grep-style search instead of loading into memory"
- Add confidence check: "If multiple matches found, list them and ask user which one"
- Consider using `Filesystem:search_files` to find block IDs without reading entire file
