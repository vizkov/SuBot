## DAG Continuous Learning

### Continuous Learning System
**Reference**: [ChatGPT Discussion](https://chatgpt.com/c/68d694d9-e5b4-8332-af51-3bb21e06e7f1)

**Characteristics:**
- Highly configurable sources to develop/learn/practice
- Adopts Character Progression System design patterns
- Can attain skills
- Pre-configured with sets of skills it can hone
- Can identify takeaways from experiences to form into skill-progress
- Can identify skills gap within existing skillset
- Can look for new skills

**Learning Methods:**
- **Active Learning**: Labs, CTFs, and Challenges
- **Passive Learning**: CTI reports, Research Papers, and Bug Bounty reports
